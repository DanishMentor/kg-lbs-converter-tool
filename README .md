# mass-converter-js

A lightweight, zero-dependency, bidirectional mass conversion tool written in pure HTML, CSS, and Vanilla JavaScript. Converts Kilograms (kg) to Pounds (lbs) in real time with precision rounding.

## Features
- **Bidirectional Sync:** Type in KG to calculate LBS, or type in LBS to calculate KG.
- **Custom Steppers:** Integrated numeric stepping controls.
- **Preset Buttons:** Instant evaluation for standard units.
- **Zero Dependencies:** Pure vanilla JavaScript, no framework bloat.
- **Responsive Design:** Optimized for mobile, desktop, and embedded widgets.

## Installation & Usage
No build step required. Simply open `index.html` in any browser or embed the snippet directly into any static web page.

## Formula
1 Kilogram (kg) = 2.2046226218 Pounds (lbs)
